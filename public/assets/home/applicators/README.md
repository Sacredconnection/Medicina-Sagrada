# Imagens da seção Aplicadores

Use arquivos WebP sRGB com estes nomes e proporções:

- `medicina-sagrada-aplicadores-tepis.webp` — 1600 × 800 px (horizontal, proporção 2:1)
- `medicina-sagrada-aplicadores-kuripes.webp` — 1600 × 1600 px (quadrado, proporção 1:1)
- `medicina-sagrada-aplicadores-reservatorios.webp` — 1600 × 1600 px (quadrado, proporção 1:1)

Comprima cada arquivo para até 400 KB. Mantenha o assunto principal dentro dos 80% centrais para permitir o recorte responsivo com `object-fit: cover`. Evite detalhes importantes no quarto inferior esquerdo, onde aparece o nome da categoria.

Os três nomes acima já estão conectados à seção. Em desenvolvimento, arquivos novos ou substituídos são detectados automaticamente e atualizados no navegador sem reiniciar o servidor.
