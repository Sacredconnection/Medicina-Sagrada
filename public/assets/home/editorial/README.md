# Banners editoriais da página inicial

- Dimensão: 1600 x 1600 px
- Proporção: 1:1
- Formato: WebP, sRGB
- Peso recomendado: até 400 KB por imagem

Arquivos:

- `medicina-sagrada-editorial-sananga.webp`
- `medicina-sagrada-editorial-acessorios.webp`
- `medicina-sagrada-editorial-incensos.webp`

Não aplique textos na arte. O conteúdo editorial é inserido em HTML sobre a
imagem e precisa continuar editável e responsivo.
