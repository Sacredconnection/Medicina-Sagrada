# Imagens dos pilares institucionais

Esta pasta recebe as três fotografias da seção **Conhecimento vivo, relações de respeito** da página inicial.

## Especificação comum

- Dimensões: `1200 x 1200 px`
- Proporção: `1:1`
- Formato: `WebP`
- Perfil de cor: `sRGB`
- Transparência: não necessária
- Peso recomendado: até `300 KB` por arquivo
- Qualidade WebP sugerida: `80–85`
- Enquadramento: mantenha o assunto principal dentro dos `80%` centrais
- Comportamento no site: recorte com `cover`

Exporte os três arquivos com os nomes exatos acima. Depois de inseridos, atualize as referências em `app/page.tsx` para os respectivos caminhos públicos. Não substitua as imagens da pasta `public/assets/home/categories`, pois elas também são utilizadas em outras áreas do site.
