# Imagens da seção Artesanatos

Salve as duas imagens finais nesta pasta com os nomes exatos abaixo:

- `medicina-sagrada-artesanato-destaque-01.webp`
- `medicina-sagrada-artesanato-destaque-02.webp`

## Especificações recomendadas

- Dimensões: `1600 x 2000 px` para cada imagem (proporção 4:5)
- Formato: WebP
- Perfil de cor: sRGB
- Peso recomendado: até 500 KB por arquivo
- Área segura: mantenha o assunto principal dentro dos 78% centrais da imagem

O enquadramento é feito com `background-size: cover`. A primeira imagem aparece
maior e a segunda aparece menor e deslocada na composição. Ao substituir os
arquivos mantendo esses nomes, nenhuma alteração no código será necessária.
