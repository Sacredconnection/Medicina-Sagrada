# Imagens de produtos

As imagens principais continuam sendo fornecidas pelo WooCommerce. Esta pasta é
reservada para fallbacks ou produtos que precisem de um asset local.

- Dimensão: 1600 x 1600 px
- Proporção: 1:1
- Formato: WebP, sRGB
- Peso recomendado: até 350 KB
- Nome: `produto-[slug-do-produto].webp`

Exemplo: `produto-rape-yawanawa-tsunu.webp`.
