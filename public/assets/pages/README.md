# Imagens de páginas internas

Crie uma subpasta com o slug de cada página antes de adicionar arquivos.

Exemplo:

`pages/sobre-nos/medicina-sagrada-sobre-nos-hero.webp`

Padrão inicial para banners internos:

- Dimensão: 2400 x 1200 px
- Proporção: 2:1
- Formato: WebP, sRGB
- Peso recomendado: até 700 KB

Se a composição exigir outra proporção, documente a dimensão no README da
subpasta correspondente.
