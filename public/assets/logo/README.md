# Logotipo

Cores oficiais confirmadas por Danilo em 26/10/2026: verde `#1a4020` e
laranja `#ef4929`. O SVG horizontal e o favicon foram alinhados; o favicon
preserva a variante branca no modo escuro.

Coloque nesta pasta o arquivo final com este nome:

`medicina-sagrada-logo-01.svg`

Especificação recomendada:

- formato: SVG vetorial;
- prancheta: 1200 × 300 px, proporção horizontal 4:1;
- fundo: transparente;
- texto convertido em curvas/outlines;
- sem imagens raster incorporadas;
- manter uma margem de segurança ao redor do desenho.

O arquivo está integrado como o lockup horizontal do header. Ao substituí-lo
mantendo esse nome, não será necessário alterar o componente.
