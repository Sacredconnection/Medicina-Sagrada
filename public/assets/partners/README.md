# Logotipos das lojas parceiras

- Sacred Connection: `sacred-connection-logo.svg`
- Maya Herbs: `maya-herbs-logo.svg`

Exporte como SVG com fundo transparente e prancheta ajustada ao desenho.
Tamanho recomendado: 600 × 200 px, com `viewBox` correspondente.
A proporção original pode ser mantida: o site encaixa o logo sem cortar nem distorcer
em uma área de até 200 × 72 px, no desktop e no mobile.
Converta textos em curvas e incorpore os elementos no próprio SVG.

Sem o arquivo, aparece o nome da loja. No localhost, inserir ou substituir o SVG
atualiza automaticamente a página aberta. No site publicado é necessário um novo deploy.
